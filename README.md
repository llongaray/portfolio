## Publicar no GitHub Pages

### Opção A — Site pessoal (recomendado)

1. Crie o repositório **`llongaray.github.io`** no GitHub
2. Envie todos os arquivos mantendo a estrutura de pastas
3. Vá em **Settings → Pages → Source: Deploy from branch**
4. Selecione branch **`main`**, pasta **`/ (root)`**
5. Acesse: **https://llongaray.github.io**

### Opção B — Repositório separado

1. Crie um repo (ex.: `portifolio`) e envie os arquivos
2. Ative GitHub Pages na branch `main`, pasta root
3. URL: **https://llongaray.github.io/portifolio**
